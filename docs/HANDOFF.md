# ReliableEvent 当前交接

## 当前进度

M0、M1 和完整 M2 已完成。项目已经具备经过双 Worker 并发测试的条件抢占、失败重试和死信闭环：

```text
事务内 publish → PENDING → 查询候选版本 → 条件抢占为 PUBLISHING
                                               ↓
                                      事务外 Fake 发送
                                               ↓
                                  按抢占版本更新为 PUBLISHED
```

已经实现事务校验、JSON 序列化、重复事件键幂等登记、未来事件过滤、版本号条件抢占、短事务状态更新、带随机抖动的指数退避、最大尝试次数、不可重试错误分类和 `DEAD` 终态。两个独立 Worker 使用同一候选版本并发竞争时，只有一个 Worker 能够调用发送器。

## 验证方式

启动 Docker，使用 Java 17 执行：

```bash
mvn verify
```

当前共有 10 个单元测试和 17 个 MySQL 5.7 集成测试，全部通过。

## 当前边界

- 发送端仍是测试用 Fake 适配，没有接入 RocketMQ；
- 单个 Worker 内仍然顺序处理，没有后台调度和并行线程池；
- 尚未实现租约和发布进程宕机恢复；
- `DEAD` 暂无人工重放接口；
- Spring Boot 自动配置和指标尚未开始。
